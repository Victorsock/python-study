
# Python | Exemplos de Lógica de Programação em Python
Este repositório contém exemplos de lógica de programação em Python, abrangendo diferentes conceitos e estruturas. 

O objetivo é fornecer uma coleção organizada de scripts de programação para fins de estudo e aprendizado.

# 📚 Estrutura do Repositório
O repositório está organizado da seguinte forma:

- 01-variaveis-operadores: Exemplos de uso de variáveis e operadores.

- 02-condicionais: Exemplos de estruturas condicionais como if, else, elif.

- 03-loops: Exemplos de loops como for e while.
  
- 04-dicionarios-listas: Exemplos de listas, dicionários, tuplas, e manipulação desses tipos de dados.

# 🚀 Como usar
Para usar o código deste repositório, siga as etapas abaixo:

1. Clone o repositório para a sua máquina local:

        git clone https://github.com/Victorsock/python-study.git

2. Acesse a pasta do projeto:

        cd python-study

3. Execute os scripts em Python:

 Para executar um script, use o comando:

    python nome_do_script.py

Exemplo:

        python 01-variaveis-operadores/variaveis-operadoresEx.py

# 🛠️ Requisitos:

- Python 3.x ou superior instalado.

- Algumas funcionalidades podem requerer bibliotecas adicionais. Verifique se você tem as dependências necessárias instaladas.

# 💡 Exemplos de Uso
Aqui estão alguns exemplos de uso do código:

- Exemplo de Variáveis e Operadores: Um script simples mostrando como utilizar variáveis e operadores aritméticos em Python.

- Exemplo de Condicionais: Demonstra como usar if, else, e elif para criar lógica de decisão.

- Exemplo de Loops: Mostra como utilizar loops for e while para iterar sobre listas ou realizar repetições.

- Exemplo de Listas e Dicionários: Exemplifica o uso de listas, dicionários e suas manipulações em Python.
